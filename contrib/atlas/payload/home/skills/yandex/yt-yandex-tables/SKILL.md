# YT read research

Use yt_read or catalog-approved service_read with native ACLs. Inspect exists, schema and safe attributes before bounded data. Choose explicit scalar columns and a bounded row range; distinguish static snapshots from dynamic queries. Preserve cluster, path, schema and continuation. Never write, lock, transact, change ACLs or create tables.

Read `references/restricted-contract.md` before tool use. This is a curated neutral read procedure, not the personal upstream operations manual.
