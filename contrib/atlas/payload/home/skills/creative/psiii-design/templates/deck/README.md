# Шаблон презентации ПСиИИ — как получить фирменный PPTX

**`presentation-psiii.pptx`** — приложенный шаблон, включён без изменений. Это
**основа** всех дек: 18 именованных макетов, тема (F2F2F2 / красный F66048), шрифты
YS Display Cond Heavy + YS Text, 116 направляющих, размер 67,73 × 38,1 см. (Тот же
файл лежит как `../business-pptx/source.pptx` — его использует сборщик.)

## Как получить деку в правильном шаблоне — попроси ассистента

Самый надёжный путь — **сказать ассистенту**, например:

> «Собери презентацию о <теме> по дизайн-системе ПСиИИ и дай готовый PowerPoint.»

Ассистент соберёт деку **прямо в шаблоне** через `buildBrandPptx`
(`../business-pptx/build-pptx.js`): ты описываешь слайды (заголовки, тексты, цифры,
карточки, фото), а он раскладывает их по фирменным макетам. На выходе — редактируемый
`.pptx` с правильной темой, шрифтами, сеткой и макетами, готовый для дальнейшей
самостоятельной работы в PowerPoint. Фирменность гарантирована по построению, файл
проходит проверку из 15 инвариантов.

Если дека уже свёрстана в HTML (превью на deck-stage) — ассистент экспортирует её
через `gen_pptx` → `finalize-pptx.js` (тот же фирменный результат).

## ⛔ Не используй кнопку Share → Export → PowerPoint

Эта кнопка конвертирует HTML с экрана в плоский PPTX **мимо шаблона**: дефолтный
размер 13,33″, тема Office, один макет вместо 18, без направляющих, финал красный.
Такой файл нефирменный и для дальнейшей работы не годится. Фирменный шаблон даёт
**только** сборка через ассистента (выше) — не кнопка экспорта.

> Источник правды — `source.pptx`. Деки собираются в нём, а не пересоздаются «на
> глаз», чтобы шрифты, сетка, цвета и макеты не расходились с оригиналом.
