# UI kit — Презентация ПСиИИ

The presentation template is the **original PowerPoint file**, included unchanged:
`presentation-psiii.pptx` (the attached `Slides_CD` deck — 11 slides: title, agenda,
section, thesis, text, two-column, metrics).

`index.html` is a branded cover that links to the file (Открыть PPTX). Edit the deck
in PowerPoint — it is the source of truth.

> Live HTML cannot render PowerPoint slides as images. If you want the slides shown
> as exact pictures inside the design-system tab, export the PPTX to PDF or PNG and
> they can be embedded pixel-for-pixel.
