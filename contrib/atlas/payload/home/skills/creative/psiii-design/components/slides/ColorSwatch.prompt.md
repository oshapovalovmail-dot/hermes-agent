A sharp (0-radius) color block with its hex value beneath — exactly how the brandbook documents the palette on its «Палитра» slides.

```jsx
<ColorSwatch color="#FC3F1D" value="#FC3F1D" label="Яндекс" />
<ColorSwatch color="#1F1F20" value="#1F1F20" w={400} h={260} />
```

- Light colors get a 1px inset hairline so white reads on white.
- `w` / `h` default to the brandbook block (500×321 slide px).
