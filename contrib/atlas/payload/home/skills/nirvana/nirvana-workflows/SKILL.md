# Nirvana read research

Use nirvana_read for existing workflow metadata, state, graph, failed blocks and bounded logs. For other reads discover the exact catalog operation first. Correlate workflow instance, block and execution IDs; do not infer runtime state from graph definition alone. Never clone, run, abort, reject, sync or modify workflows.

Read `references/restricted-contract.md` before tool use. This is a curated neutral read procedure, not the personal upstream operations manual.
